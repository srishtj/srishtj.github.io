ipxassistant

what it is

as an it intern at clemson's watt family innovation center, i built an assistant that lets you ask about the building's av network in plain english, like which encoders in a room have no signal.

  1. scrape
  2. ask
  3. look up
  4. answer

my favorite part

it can look, but it can't touch. the assistant only sends read commands and queries a read-only database, so it can't directly change routing or settings. people still decide what to do with its answers.

what i built

  • the scraper: a background job that pulls 300+ devices and 3,000+ streams across 50 rooms into sqlite, and records what changed between scrapes.
  • the agent: read-only tools for room overviews, device details and sql lookups, so the model answers from real data.
  • model choices: it runs on claude, gemini or a free local model. on gemini’s free tier, it moves to the next model when one runs out of daily quota.
  • the panel: a flask web panel styled after the building’s touch panel.

also at watt: a java scheduling system that automates about 80% of recurring lighting operations.
